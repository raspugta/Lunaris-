# Reference documents

These sources back the rover and soil parameters in `configs/rovers.yaml`. They are linked rather than
redistributed.

* NASA VIPER Updated Technical Briefing (2025-02-13):
  https://assets.science.nasa.gov/content/dam/science/psd/lunar-science/documents/2025-02-13_VIPER_Updated_Technical_Briefing_Presentation-Shared.pdf
* Bluethmann, *VIPER Rover Overview and Mobility and Hardware*, LSIC 2024 (NASA NTRS 20240013903):
  https://ntrs.nasa.gov/api/citations/20240013903/downloads/LSIC_2024-Tech%20Infusion_Panel-VIPER_Mob-HW.pdf
* Schepelmann et al. (2025), VIPER mobility, *Planetary Science Journal*: https://aschepelmann.github.io/papers/PSJ2025.pdf
* Carrier, *Trafficability of lunar microrovers*, Parts 1–3, Lunar Geotechnical Institute (Apollo LRV Bekker values, citing
  Costes et al. 1972): https://www.lpi.usra.edu/lunar/surface/Trafficability_Part_1.pdf (Parts 2 and 3 at the same path)
* NASA Mars 2020 Perseverance rover components: https://science.nasa.gov/mission/mars-2020-perseverance/rover-components/
* ISRO Chandrayaan-3 mission details: https://www.isro.gov.in/Chandrayaan3_Details.html
* Arduino Alvik MicroPython library: https://github.com/arduino/arduino-alvik-mpy
